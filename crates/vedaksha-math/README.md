# vedaksha-math

[![crates.io](https://img.shields.io/crates/v/vedaksha-math.svg)](https://crates.io/crates/vedaksha-math) [![docs.rs](https://img.shields.io/docsrs/vedaksha-math)](https://docs.rs/vedaksha-math)

Numeric primitives for the Vedaksha engine: Chebyshev polynomials, angle arithmetic, interpolation and rotation matrices. `no_std` with the default features off.

Part of [Vedaksha](https://github.com/arthiqlabs/vedaksha), a clean-room Rust ephemeris and Vedic astrology (Jyotish) engine. Most users want the umbrella crate [`vedaksha`](https://crates.io/crates/vedaksha), which re-exports this one.
