# vedaksha-astro

[![crates.io](https://img.shields.io/crates/v/vedaksha-astro.svg)](https://crates.io/crates/vedaksha-astro) [![docs.rs](https://img.shields.io/docsrs/vedaksha-astro)](https://docs.rs/vedaksha-astro)

Chart computation on top of the ephemeris: 10 house systems, aspects with applying and separating motion, essential dignities, eleven sidereal ayanamshas each derived from a primary source, sunrise and sunset, moonrise and moonset.

Part of [Vedaksha](https://github.com/arthiqlabs/vedaksha), a clean-room Rust ephemeris and Vedic astrology (Jyotish) engine. Most users want the umbrella crate [`vedaksha`](https://crates.io/crates/vedaksha), which re-exports this one.
