# vedaksha-vedic

[![crates.io](https://img.shields.io/crates/v/vedaksha-vedic.svg)](https://crates.io/crates/vedaksha-vedic) [![docs.rs](https://img.shields.io/docsrs/vedaksha-vedic)](https://docs.rs/vedaksha-vedic)

Vedic astrology (Jyotish) from the classical texts, cited by chapter and verse: 27 nakshatras with padas, eight dasha systems (Vimshottari, Ashtottari, Yogini, Chara, Narayana, Sthira, Niryana Shoola, Maheshwara), all 16 vargas, the complete shadbala of BPHS 27, bhava bala, vimshopaka, sputa drishti, ashtakavarga, panchanga, muhurta search, and eclipse, ingress, station and heliacal searches.

Part of [Vedaksha](https://github.com/arthiqlabs/vedaksha), a clean-room Rust ephemeris and Vedic astrology (Jyotish) engine. Most users want the umbrella crate [`vedaksha`](https://crates.io/crates/vedaksha), which re-exports this one.
