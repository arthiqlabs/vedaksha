# vedaksha-graph

[![crates.io](https://img.shields.io/crates/v/vedaksha-graph.svg)](https://crates.io/crates/vedaksha-graph) [![docs.rs](https://img.shields.io/docsrs/vedaksha-graph)](https://docs.rs/vedaksha-graph)

A property-graph model and ontology for astrological charts, with emitters for Neo4j Cypher, SurrealDB SurrealQL, JSON-LD, plain JSON and RAG embedding text.

Part of [Vedaksha](https://github.com/arthiqlabs/vedaksha), a clean-room Rust ephemeris and Vedic astrology (Jyotish) engine. Most users want the umbrella crate [`vedaksha`](https://crates.io/crates/vedaksha), which re-exports this one.
